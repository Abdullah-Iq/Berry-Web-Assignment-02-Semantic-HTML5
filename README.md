# Berry — Web Technologies Assignment 02

## Assignment
**Use HTML5 semantic tags in the previous Assignment 01 project.**

This version keeps the original Berry five-page website and improves its document structure with meaningful HTML5 semantic elements without changing the visual design.

## Semantic HTML5 elements used
- `<header>` — site/page header areas
- `<nav>` — primary and mobile navigation
- `<main>` — unique main content of each page
- `<section>` — logical content sections
- `<article>` — independent cards/content units
- `<aside>` — supplementary information and feature panels
- `<footer>` — shared site footer
- `<form>` — Sign In, Sign Up and Contact forms
- `<figure>` and `<figcaption>` — Home page performance visualization
- `<address>` — Contact page contact information
